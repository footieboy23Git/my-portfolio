## Impact Highlights
* **66 users automated** across the studio.
* **1,650 annual holiday days** automatically synced into capacity planning without manual entry.

## Situation
Holiday tracking required manual updates across HR systems and studio scheduling tools. This created administrative friction and risked capacity discrepancies when leave was booked or updated but not manually reflected in studio boards.

## Action
* **System Integration:** Built an automated integration using Make to connect BambooHR with monday.com.
* **Automated Sync:** Automated the end-to-end sync of approved holiday, out-of-office dates, and return times directly into studio availability.
* **Error Prevention:** Eliminated manual data entry barriers to ensure real-time capacity accuracy across all regional teams.

## Result
Removed manual administrative overhead while providing studio leadership with accurate, real-time availability dates for resource scheduling.
